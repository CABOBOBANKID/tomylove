PREVIEW ON YOUR COMPUTER
1. Extract this ZIP to a folder.
2. Open index.html in Chrome or Edge.
3. To preview before midnight, add #preview to the address, e.g. file:///.../index.html#preview
4. The opening button starts the music because browsers require a user action before audio can play.

IMPORTANT
Keep the img and media folders next to index.html. Do not rename or move them unless you update the paths in index.html. The birthday gate is set for 12 October 2026 (midnight local browser time via UTC; Ghana uses UTC).
